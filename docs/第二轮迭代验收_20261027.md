### 目标与论文覆盖

原始 LLM Top-3：

1. `arxiv:2303.11366` — Reflexion: Language Agents with Verbal Reinforcement Learning。
2. `arxiv:2509.03990` — Meta-Policy Reflexion: Reusable Reflective Memory and Rule Admissibility for Resource-Efficient LLM Agent。
3. `arxiv:2603.14597` — D-MEM: Dopamine-Gated Agentic Memory via Reward Prediction Error Routing。

Reflexion 原始论文已真实入选，但全文提取不完整。一次候补下载失败后，`openalex:W4400525295`（On Generative Agents in Recommendation）完整提取成功，最终分析它与上述第 2、3 篇。最终三篇分别为 11、9、15 页的完整 Markdown；完整提取不代表总结成功。

目标审计显示 Reflexion 有 8 个标题词面匹配、Generative Agents 有 9 个标题词面匹配；A-Mem 没有直接标题匹配，只有 2 个摘要提及。标题匹配包含后续或无关工作，不能当作已验证原始论文身份。此次没有凑齐题目指定的三个原始工作，不能声称已经完成它们的直接比较，也不能以可下载的相关论文冒充指定对象。

### 总结失败与实测后的补丁

实际失败均定位到 `evidence.*.evidence_type` 的 `literal_error`。原始输出是合法 JSON，因此模型 HTTP usage 中 `invalid_outputs=0` 不表示通过了后续研究 schema 校验。全部失败信息保留，未删除非法证据或放宽枚举来伪造成功。

核对源码发现，新 `CHUNK_SYSTEM` 列出了 `evidence_type` 字段，却没有列出允许值。协调者在实测后补充了明确提示：只允许 `author_claim`、`system_inference`、`research_idea`，机器枚举不得翻译或改名。该小补丁已通过 AST 与 Ruff；**补丁之后没有重跑真实模型，不能宣称它已解决本次错误**。本轮原始产物对应补丁前的源码，忽略目录中的源码清单保留了该边界。
