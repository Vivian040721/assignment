# Paper Agent v0.3.0 交付说明

日期：2026-10-28。后续开发统一使用长期分支 `dev`，通过 PR 提交到 `main`；不创建 `v0.3.0` 等版本号命名的开发分支。

## 用户可见改进

- 研究简报优先呈现关键发现、关键论文与具体研究下一步，排序分数、处理阶段和技术错误在执行记录中按需查看。
- 实际分析材料与原始 LLM 精选分别保留；原始选择不再覆盖已经获取的全文，替补论文可以关联到总结、简报及 PDF。
- 应用内 PDF.js 阅读支持真实页面显示、翻页、缩放、全文查找与专注阅读；文件仍通过已有受控 Electron API 读取。
- 分块证据、有限输入综合和标题定向查询保留真实来源与不完整交付边界。

## 版本与接口

Python 项目元数据、Python 运行时、桌面 package、renderer package 及 npm lockfile 的项目/workspace 元数据均为 `0.3.0`。本次升版未改变依赖解析结果，API 仍为 v3。

测试中的现有版本断言和 Mock ServiceInfo 已同步为 `0.3.0`；这不代表重新执行了测试套件。历史交付、实验与安装包记录继续保留产生时的版本。

## 已有功能实证与限制

升版前对相同功能代码的独立桌面体验已观察到真实 PDF 页面、翻页重绘、全文搜索 51 处匹配及扩大阅读；原长上下文任务的三篇关键论文关联已恢复。

最新独立研究问题为“不确定性估计与拒答”。该次真实 MCP 流程检索得到 43 篇去重候选，主流程耗时 349.21 秒；完整全文 0、部分全文 1、可用部分总结 1，报告有正文但 `report_valid=false`，交付为 `preliminary_notes`。实际模型用量为 6 次 HTTP、18,858 tokens。

全文获取失败、简报结论重复和引文不足以直接支持效果比较的问题尚未解决。界面和阅读能力的改善不能表述为科研质量已经完整通过；本次版本变更也不是新的研究实验或受控优化对照。

原始研究数据、PDF、截图、本机配置与密钥保留在 Git 忽略的运行目录或用户资料目录，不纳入提交。既有安装包仍保留旧版本，`0.3.0` 当前交付范围为源码与 PR。
