## 共同完成定义

- 交付源码 + 运行命令 + 输入输出样例 + 测试/核查证据 + 已知限制。
- 不提交 `.env`、虚拟环境、模型文件、下载的论文或运行输出。
- 每日晚间由 01 集成；02/05 审核 schema 变更；依赖新增由组长统一锁版本。
- 遇到真实接口或全文失败，先记录原因，不删除失败结果来美化成功率。
- 功能首交和正式验收分开：代码能调用不等于相关性、总结准确性或优化收益已通过。
