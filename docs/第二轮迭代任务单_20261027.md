## 1. 目标召回与受限候选池

主要所有权：角色 4（`services/retrieval.py`）、角色 5（`agents/selector_agent.py`）、角色 1/8（`services/pipeline.py` 集成）；来源角色 2/3 仅修复确认的问题。

- 同一次查询规划调用返回来自用户原话的 `explicit_targets`、最多 3 条真实来源查询、独立的 `ranking_query`。目标须做 NFKC/空白/大小写标准化与原文存在检查；不接受模型补充的论文名、别名或已知 ID。一般问题可没有 targets，保持兼容。不能为 Reflexion 等具体工作写代码特例。
- 最多 3 条查询保持原来源请求规模；3 个点名目标时可用 3 条定向查询，ranking_query 单独描述整体问题用于现有 SBERT。超额目标保留记录并明确查询覆盖不足，不伪造已查询。
- 不更改 SBERT/RRF 模型、权重、线程、缓存与降级逻辑。在全部去重重排之后，完整有序候选池保存在 run 中，供有限候补；构造独立、有界的 Selector 输入池，遵守 merged/candidate/input 预算。
- 仅保护真实检索到的直接标题匹配候选进入受限输入池；池外目标匹配可替换池内末端非目标候选，数量不变，保持稳定顺序与审计。标题匹配、摘要仅提及、未检索到分别记录，不把提及当原始目标论文。
- Selector 获得目标与匹配信息，提示优先直接原始工作并覆盖点名对象。最终仍由真实 LLM 选择，不用确定性规则硬替换其最终 Top-k，不编造 final_score，不改写原始 selected_papers。遗漏覆盖如实记录。
- targets 与匹配、原始/选择池 ID、截断与覆盖结果放现有 metadata/metrics，尽量不加公共 Pydantic 字段；现有独立模块函数兼容旧调用。

## 2. 有界全文候补与可追溯性

主要所有权：角色 6（`services/downloader.py`、`pdf_converter.py`）与角色 1/4（`services/pipeline.py`）。

- 候补使用完整候选池；在原有限制内，优先目标同对象直接匹配和已有 OA PDF URL 的候选，其他按融合排名稳定排序。OA 只影响全文尝试顺序，不能冒充学术相关性。
- 新增运行级 `replacement_attempts` 审计所有候补（不只成功）：候补 ID、可确定的原始 ID/无对应时 null、顺序、真实状态、失败码、是否进入 analysis、实际 summary scope。保留 `replacements` 的完整成功替补语义。部分全文进入分析需明确部分候补身份。
- 不增加默认下载限制；验收进程沿用 `PAPER_AGENT_MAX_FULLTEXT_ATTEMPTS=4`（核查当前代码这是候补次数，不含原始 Top-k，文案不能误称总共 4 篇）。不扩大尝试/超时预算。不得把无关的可下载论文说成补齐了点名目标。
- 完整/部分/不可读仍由真实 PDF、Markdown、page_map、fulltext_quality 决定；保留全部错误，不下载任意外部内容，不绕过安全约束。没有确定修复点的下载/转换文件可不改。

## 3. 分离分块抽取与整篇综合

主要所有权：角色 7（`agents/research_agent.py`），角色 1 只协调现有公共类型。

- 将 chunk 提示与 merge 提示彻底分开，内部 schema 也可分开。chunk 只提取精简结构化事实与少量连续原文证据，不再要求每块 900–1800 字 deep_analysis/overview。
- chunk 只能使用当前 `source_segment_id`、真实页码/section 和逐字 quote，明确禁止 `evidence_id`；后者仅 merge 时由程序给已验证记录分配。不能通过容忍/删除任造 ID 或跨 segment 拼 quote 来掩盖失败。
- 维持严格 NFKC/空白标准化、单段命中、paper/page/section/claim 校验。区分“引用真实性校验”与事实主张支持程度，不能把机械 quote 命中描述为整篇科学结论已验证。
- 每篇最多一次反馈修复（chunk 与 merge 共享），不是每 chunk 一次；模型/请求/总 token/输出上限不提升。
- 基于已验证、精简的分块笔记，在现有论文级合并调用中一次生成 overview 与 deep_analysis。避免 merge payload 同时重复每块 evidence 全记录与 verified_evidence；可用 ID 关联，同一份原文目录严格还原。保留所有已校验证据的完整 artifact。
- 不通过无记录截断事实/实验/局限来凑进输入预算。若必须有界选取，明确 omissions 与 scope/合并降级；无法综合时保留结构化笔记，显示未完成整篇综合，不把数千字重复拼接假装高质量深度笔记。单 chunk 论文也应有合理的论文级笔记路径，预算不足如实降级。
- 全部 chunk 是否分析、全文是否完整、summary errors、report_valid 继续由真实数据判断；不为了 completed 放宽。原始 PDF 与 Markdown 完整保留，报告只引用实际最终分析的可用总结。
