## 4. 主进程、preload、IPC、快捷键、窗口与服务连接

- **主进程**：逐项只读核查后仅做一处结构性改动——`installWindowShortcuts` 从 `main.ts` 抽到 `electron/shortcuts.ts` 并注入 `packaged`/`quit`，行为完全不变（编辑键 → `preventDefault` + 动作；`Meta+Q` → 退出；`F5`/`Ctrl+R`/`F12`/`Ctrl+Shift+I` 仅非打包时生效）。
- **快捷键为何用单测而非 E2E**：Playwright 通过 CDP 分发按键，**不会**触发 Electron 主进程的 `before-input-event`（实测 `page.keyboard.press('F12')` 后 `isDevToolsOpened()` 始终为 false）。本轮因此改为对 `installWindowShortcuts` 做确定性单测（4 例：打包版编辑键、Meta+Q 退出且 Ctrl+Q 不退出、F5/F12 仅开发版、无关键与 keyUp 忽略）。
- **preload / IPC**：白名单 `contextBridge` API 与 `assertTrusted`（主窗口、主框架、file: 指向内置 renderer 或 dev origin 5173）经核查无需改动；`registerHandler` 统一错误脱敏；artifact 打开/导出经 `safeFilename` 限制扩展名、kind 与绝对路径。
- **窗口与服务连接**：token 只存在于主进程 `ServiceClient`，不进入 renderer 与诊断日志；SSE 订阅有界（单发送者 ≤32、序号去重、45s 看门狗、指数退避、401/403/404/410 语义区分），窗口导航/销毁/渲染进程消失时清理；服务单实例由 `service_control` 锁文件保证，关窗不停止服务（E2E `daemon-survives-window-close` 实证，含真实 MCP 客户端调用）。

## 5. E2E 新增覆盖（iteration-2 桌面可见契约）

新增检查 `report-validity-scope-readable-comparison-stable-numbering`：

- 报告状态、任务状态、报告有效性三个 chip 必须分别展示且互不混淆：demo 任务只有 1 篇总结（少于 3 篇）→ 状态「部分结果报告」，但 `report_valid=true` → 「报告有效」，任务状态「演示完成」。正对第二轮任务单「部分总结被引用不等于报告有效」「分别展示」的要求。
- 报告范围计数展示总结 scope（「演示样例」），不与「全文完整」混同。
- 报告比较段在**存储 artifact 原文**与**前端渲染结果**两处都必须为可读 Markdown（`## 论文比较`、`### 比较 1：[demo:001]`、`synthetic fixtures only`），且不得泄露 `"paper_ids"` 原始 JSON——锁定 iteration-2「比较从 JSON 行改为可读 Markdown」的后端契约与前端渲染兼容。
- 最终分析列表主编号为稳定 1..N（`.paper-rank` = 1），论文行标签区分「演示样例」scope、「全文完整」、「报告已引用」。
- 该断言块结束时会把 Dock 切回报告标签页，保持后续检查的 UI 状态不变（避免报告视图重新挂载导致截图等待超时）。
- 源码模式启动优先复用 `node_modules/electron/dist` 中与 devDependency 固定的二进制（`PAPER_AGENT_ELECTRON_EXE` 可覆盖），规避受限网络下 Playwright 从 CDN 下载 Electron 超时导致 E2E 无法启动的问题；不影响原有打包模式参数。

## 9. 已知风险与限制

1. `onnxruntime` ≥1.21 在本机不可用（access violation）；本机 venv 使用 1.20.1 完成验证。lock 文件未改，需角色 1 决策是否增加 CPU 兼容上限。若在其他机器按 lock 重建环境，行为以该机为准。
2. 主进程快捷键无法用桌面 E2E 验证（Playwright CDP 按键不触发 `before-input-event`），已改为单测覆盖；若后续有人依赖 E2E 验证快捷键，需要先解决输入通路。
3. E2E 对 demo 夹具的结构断言（chip 文案、编号、比较段格式）与 iteration-2 后端/前端契约绑定；后续契约变更需同步更新断言。
4. E2E 源码模式复用本地 Electron 二进制；若 `node_modules/electron` 缺失且网络不可达，E2E 仍会因无法下载 Electron 而失败（此时应提示而非静默）。
5. 本轮未运行 live 研究、未调用真实模型；桌面结论不构成论文质量或性能证据。
6. 打包产物位于 gitignore 的 `data/release/`，不会入库；长途路径/磁盘空间未在本轮复测。
