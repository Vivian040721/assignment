## 1. 用户可见结果

- 原生菜单栏已移除；复制/粘贴/撤销/重做/全选、开发刷新和 DevTools 快捷键仍可用。
- 运行时的自由文本、错误说明、阶段、工具、状态和论文状态显示为中文；论文标题、引文原文和机器码保持原文。
- Dock 标签栏按面板实际宽度自适应；标签多时出现左右滚动和“更多资料标签”菜单，完整标题可从菜单读取；分栏、拖拽、Resize 和全屏后重新测量。

- 活动记录按阶段/工具聚合为可展开卡片；错误卡片默认展开，参数展开后脱敏。
- 默认 Dock 只保留论文标签；报告、活动、性能数据按需打开；设置不再重复出现在添加菜单。
- 输入框支持 72–190px 自增高、字数计数、运行中继续起草；对话内显示最近阶段流。
- PDF 下载使用单候选 45 秒、单篇总预算 180 秒、连接 5 秒、最多 8 个候选；慢候选不会独占整篇预算。
- 版本更新为 0.2.2。

## 3. 关键根因与修复

### 3.1 Sidebar（延续 v0.2.1）

折叠轨道 58px 时品牌标记、间距和箭头按钮总宽超过可用宽度，展开按钮被 `overflow:hidden` 裁切。v0.2.2 延续单一 rail 状态源、footer 展开控制，并新增 1024px/刷新回归；本轮未回退。

### 3.2 论文“当前任务中找不到”

三个根因：

1. `utils/papers.ts` 为避免重复展示，把替补 ID 从 `analysisPapers` 排除；`PaperReader` 只查 Top-k + analysis，导致点击替补必失败。
2. 标签只有 `paperId`，没有所属 job；切换会话/重启后仍用当前结果解析旧标签。
3. 远程/聊天任务时 `artifactJob` 可能没有研究 artifacts。

修复：

- `collectPapers` 新增 `paperById`，包含 Top-k、analysis、replacement 和全部候选。
- `LayoutTab` 新增 `jobId`；paper 标签 ID 为 `paper:<jobId>:<paperId>`；`PaperList` 传入结果 job。
- `PaperReader` 在标签 jobId 与当前结果 job 不同时通过 `desktopApi().job(tab.jobId)` 懒加载所属任务；加载态显示骨架，失败显示明确错误。
- E2E 已验证：打开论文详情 → 新建会话 → 再点旧论文标签仍显示 `.reader-view`。

### 3.3 Dock 标签栏

根因：固定 `max-width:190px`、关闭按钮固定占宽、滚动条隐藏且无溢出入口、没有按面板宽度测量。修复：

- `measureDockTabs` 计算 104–184px 自适应宽度；
- `.dock-tabs-scroll` 溢出滚动，左右按钮；
- 标签数量 >2 或溢出时提供“更多资料标签”菜单（完整标题）；
- active tab `revealTab` 自动滚入；
- `ResizeObserver` 覆盖 Dock resize、分栏、窗口 resize、全屏；
- 关闭按钮/焦点环不再被标签槽裁切。

### 3.4 PDF 超时

`download_timeout` 是单篇总预算，旧默认 60 秒；`http_timeout=30` + 2 次重试，单个慢候选最坏可耗尽 60 秒。修复：

- 单候选预算 45 秒（`download_candidate_timeout`），单篇总预算 180 秒；
- 连接超时 5 秒；
- 候选上限从 12 降到 8；
- 某个候选超时后继续下一个候选，只有整篇总预算耗尽才产生 `download_timeout`；
- 错误保留 code/details，消息中文；
- 回归覆盖“慢候选超时后第二个候选成功”和总预算硬截断。

### 3.5 中文化

- summary/report/selector 提示要求简体中文，但 `evidence.quote`、`evidence.section`、`references.title`、paper_id、JSON 键和枚举不改写。
- 后端 `_error`、warnings、partial_reason、下载/转换/来源错误改中文。
- 前端新增 `labels.ts`，统一 status/stage/tool/kind/scope/paperStatus/error code；未知值使用“未知状态（code）”而不是裸英文。
- 机器码保持稳定，历史英文记录不回写、不机翻。

## 4. 真实验证

### 4.1 小规模 live（v0.2.2 代码）

- 证据：`data/validation/v021/stress/20261024T143559Z/`
- arXiv 6 + OpenAlex 6；Selector 选中 1；真实 PDF 下载/转换 1 篇 partial fulltext；1 份中文 `partial_fulltext` 总结；中文报告 4,321 字符、1 条真实引用；整体 `partial`。
- 8 次物理模型请求、37,899 token、约 227.6 秒；下载阶段出现 `candidate_timeout`，没有旧的 `download_timeout`。
- 保留无 OA、部分页提取、候选超时、模型输出校验等真实错误。
- 结论：中文报告、单篇总结、错误中文化和双层超时已实际执行；不证明论文质量或完整成功。

### 4.2 大规模

v0.2.2 没有重新运行 40/40/30/8；v0.2.1 的 40/40/30/8 证据（`data/validation/v021/stress/20261024T095920Z/`）仍然有效，但不能表述为 v0.2.2 的新性能结果。本轮也未做 v0.2.1↔v0.2.2 同输入配对基准，因此不提供加速比。
