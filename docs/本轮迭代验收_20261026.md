# v0.2.2 本轮迭代验收 · 2026-10-26

本轮已实现 Sentence-BERT 语义重排、总结证据诊断与有限修复，并调整桌面论文列表、全文阅读和报告展示。唯一一次真实研究运行结束于 `partial`，不能据此声称研究完整成功或质量优于上一版。用户随后明确授权提交、推送和创建 PR，并确认保留 `v0.2.2`，不升版本；这覆盖本地任务单中的禁止提交和推送限制。

## 变更与验证范围

- 保留 MainAgent → 官方 MCP Client → MCP Server → 任务 Agent 的实际链路，未用直接函数调用代替 MCP。
- `semantic` 模式在全部去重候选上用 `sentence-transformers/all-MiniLM-L6-v2` 编码，随后按 `0.5/(60+keyword_rank) + 0.5/(60+semantic_rank)` 融合，再截断并交给 LLM Top-k。默认仍为关键词模式，依赖或模型不可用时记录真实降级。
- 总结和报告保留严格证据校验，增加安全诊断、预算内一次修复和明确的部分输入标记；前端展示真实排序、最终分析论文与原始入选审计、部分结果和错误详情。
- Qoder 后续追加的深度研究笔记、全文概览、报告正文范围整理、最终分析 Top-k 主视图以及默认 `max_chunks=16`，晚于下述唯一一次真实运行。最终源码已重新通过类型检查和构建，但这些追加行为没有重新提交真实研究验证；原始运行使用 `max_chunks=12`。
- Qoder 的实现与角色边界详见 [本轮迭代交付](本轮迭代交付_20261026.md)。其中“未构建/未验收/未推送”描述的是 Qoder 交付时的状态；协调者的最终检查和用户后续授权以本文为准。
