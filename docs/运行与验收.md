# 运行与验收

本文定义 v0.2.2 的安装、开发、打包和验收范围。只有实际执行过的命令和桌面流程才可写为通过。

## 环境

- Windows 11（本轮实测）、Python 3.11+（`.venv-v2`，实测 3.13）、Node.js 22+（实测 24）、Electron 45。
- 默认 data root：`%LOCALAPPDATA%\Assignment\PaperAgent`，可用 `PAPER_AGENT_DESKTOP_DATA_DIR` 覆盖。
- 密钥只写本机 `config.json`；不要提交 `.env`、`config.json` 或用户研究资料。

## 源码开发与运行

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev-desktop.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop.ps1
```

`dev-desktop.ps1` 启动 Vite HMR + Electron；窗口刷新/HMR 不会取消 Python 服务持有的任务。

## 真实运行

小规模 live 运行会访问 arXiv/OpenAlex、模型和公开 PDF，可能产生 API 用量；必须显式加 `--yes`。示例：

```powershell
.\.venv-v2\Scripts\python.exe -X utf8 scripts\stress_run.py --mode live --yes `
  --k 1 --source-limit 6 --candidate-limit 6 --merged-limit 6 `
  --max-fulltext-attempts 2 --max-llm-calls 24 --max-total-tokens 150000 `
  --max-chunks 4 --report-budget 64000 --download-timeout 180 --download-candidate-timeout 45
```

结果写入 `data/validation/v021/stress/<时间>/stress-summary.json`。PDF 下载采用单候选 45 秒、单篇总预算 180 秒、连接超时 5 秒、最多 8 个候选；超时只降级当前论文，保留错误码和中文说明。

## Windows 构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-desktop.ps1
```

v0.2.2 打包输出建议使用独立目录 `data/release/desktop-v022`，避免覆盖旧安装包。若 GitHub TLS 不可用，`winCodeSign` 无法下载，可临时使用本地 Electron 分发并设置 `signAndEditExecutable=false`；此时 EXE 文件元数据可能仍是 Electron 版本，应用内版本以 `ServiceInfo.version` 为准。安装向导和 macOS 不在本轮默认验收范围。
